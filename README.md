### Sofi - suckless app launcher for wayland

## Installation

1. build it using [nob](https://github.com/tsoding/nob.h) (feel free to modify `style.h` to change the looks of the launcher)
2. copy-paste both `sofi` and sofi_worker into `/usr/bin`
3. modify the config of your compositor of choise to execute `sofi_worker` at startup (that's the process that actually launches the apps)
4. (optional) asign `sofi` to a keybind for convinience
5. enjoy :D
